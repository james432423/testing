# Logos

- `ida-icon.svg`: the app icon. Oat (#eeeae3) mark on forest green (#1f5a43). Use at 48px and up.
- `ida-icon-small.svg`: the same mark with a thicker tick and stem, for 16–32px (browser tab, favicon).
- `ida-icon-dark.svg`: the app icon with a faint light edge, for dark surfaces.
- The wordmark is type, not a file: see the Wordmark component.
