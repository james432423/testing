The Connected apps screen: each tool the owner connected, exactly what Ida can see and do in it, and anything broken first.

- An app with a problem sorts first and uses `ida-app.is-problem` (`problem-soft` ground, the word "Problem", one Reconnect button, and what is waiting on it: "2 showings wait for this").
- Each `ida-app`: `ida-app__logo` (a neutral tile with the app's initial; never use the vendor's logo in mocks), name, status, last activity, then `ida-facts` as two short lists: "Ida can see" and "Ida can do". Use real verbs ("Draft and send email you approve"), not scopes.
- Not-connected apps show one line on what connecting would unlock and a secondary Connect button.
- Rail: "Your data" in plain words: what is stored, what is not, how to disconnect and delete.
