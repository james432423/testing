# Logo

**Not approved.** The founder rejected this tick-over-the-i icon; a replacement is being designed. Until then, use the wordmark only.

The app icon: the wordmark's tick-over-the-i on a forest green tile. It is for places that need a square mark (app icon, browser tab, social avatar). Headers and the sidebar use the wordmark alone, never icon plus wordmark side by side (it reads as "i ida").

- Mark in oat `#eeeae3` on `brand` `#1f5a43` (about 6.6:1). The tick uses the same hand-drawn path as the wordmark and the home screen ticks.
- Proportions (120 grid): stem 24 wide by 34 tall, radius 2; a 12-unit gap; the tick at stroke 12 reaches past the stem's right edge so it reads as a tick, not an "i" dot or an info glyph. The glyph is centred optically (nudged slightly up).
- Tile corner radius 24 of 120.
- Sizes: `ida-icon.svg` at 48px and up; `ida-icon-small.svg` (thicker tick and stem) at 16 to 32px; `ida-icon-dark.svg` adds a faint light edge so the tile holds on dark surfaces.
- Don't recolor the tile, outline the mark, add a tagline lockup, or place the icon on the highlighter yellow.
