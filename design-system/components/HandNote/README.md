# HandNote

The handwritten layer: a margin note, a highlighter swipe, a tick or a small arrow. It makes the screen feel like someone looked it over for you. It is never where decisions live.

- `ida-hand` (Kalam, `note` style) in `brand`: one short, warm sentence in lowercase, no period. "about 3 hours back in your week".
- `ida-marker` / `ida-cite`: a `marker` swipe only on a fact Ida pulled from a source, inside a draft. Tapping it opens the source.
- `ida-tick` (in `done`) and `ida-arrow` (in `brand`): hand-drawn SVG strokes, 2.4 wide, round caps. Copy the paths from the preview; don't draw new ones per screen.
- `ida-circle`: a hand-drawn ring around the number of an open item, in `ink`, in the sheet's margin. It turns into the green tick when the item is handled.
- The marker swipe belongs on the fact Ida pulled from a source (inside a draft), paired with a hand note that names the source.
- Never use the hand font for the question itself, numbers the owner acts on, buttons, chips, errors or anything legal.
