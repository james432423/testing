# Wordmark

"ida" in lowercase Schibsted Grotesk Bold, tightly spaced, in `ink`, with the dot of the i drawn as a hand-drawn tick in `brand` (option A). It is set in type plus one SVG stroke, so there is no image file. Option A is the chosen mark; B and C in the preview are kept for reference only.

- Classes: `ida-mark` (30px, app sidebar) and `ida-mark--lg` (72px, marketing). Use the dotless ı plus the tick SVG exactly as in the preview.
- The tick is the only colored part. Never color the letters brand, never use the hand font for the mark.
- Clear space: at least the width of the "a" on every side.
- In running text write "Ida".
