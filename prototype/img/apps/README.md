this site so the Content-Security-Policy can keep `img-src 'self'`. Nothing here is redrawn;
files are stored byte-for-byte as downloaded.

guidelines (clear space, minimum size, color, no modification, trademark attribution, and any
partnership/integration approval needed to show the mark).
