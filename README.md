# Ida

Back-office assistant for independent real estate agents. Start with **HANDOFF.md**.

- `prototype/` — clickable static prototype (live: https://ida-prototype-theta.vercel.app)
- `prototype-tests/` — Playwright tests for the prototype
- `backend/` — Next.js + Auth.js + Postgres app with the action-approval gate (see backend/README.md, backend/SECURITY_REVIEW.md)
- `design-system/` — brand book, tokens, component specs
- `accuracy-test/` — inspection-report accuracy harness
- `docs/` — decisions, research, logo options

All data in this repo is fictional sample data.
